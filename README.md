# Project CLI Python

## Deskripsi
Aplikasi CLI sederhana untuk mengelola daftar tugas (To Do List) menggunakan Python Fundamental. Dibuat untuk memenuhi Tugas Project KKA 2026.

## Fitur
- Tambah data (Menambahkan tugas baru)
- Menampilkan data (Melihat daftar seluruh tugas beserta statusnya)
- Tandai tugas selesai
- Hapus data (Menghapus tugas yang dipilih)
- Validasi Input (Mencegah error saat salah memasukkan nomor/pilihan)

## Teknologi
- Python

## Cara Menjalankan
python todolist.py
